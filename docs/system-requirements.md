# System Requirements

!!!tip Now in public beta! 🥳
SyncScript Pro is currently in public beta.\
You can download it on Apple's [TestFlight](https://testflight.apple.com/join/T1r9q74W).
!!!

SyncScript Pro requires **Final Cut Pro v12** (lifetime/perpetual) or **Final Cut Pro Creator Studio v12** (subscription) or later.

You can find Final Cut Pro's system requirements [here](https://support.apple.com/en-us/111903).

**Apple Speech Pro** functionality requires **macOS Tahoe 26 or later**.
